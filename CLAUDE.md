# Beulou Test

Application de blind test en un seul fichier : `index.html` (admin, joueurs, écran projection), données dans Firebase Firestore.

## Page d'aide

La page `aide.html` (bouton « Aide » sur la liste des sessions) doit rester à jour.
À chaque fonctionnalité ajoutée ou modifiée :

- mettre à jour le chapitre concerné dans le tableau `CH` de `aide.html` (texte simple, étapes courtes) ;
- refaire la capture correspondante dans `aide/` si l'écran a changé (JPEG, téléphone 390 px de large) ;
- changer la date « Aide mise à jour le … » en bas de la page.

Rester simple : phrases courtes, tutoiement, pas de jargon technique.
